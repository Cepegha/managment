# KPI System

**KPI** (Key Performance Indicators) — ключевые показатели эффективности. Система количественных метрик, отражающих прогресс в достижении стратегических и операционных целей.

## Core Principle

KPI — это не метрики ради метрик. Это сигналы о состоянии системы. Хороший KPI связан с целью, измерим, управляем и влияет на решения.

## Иерархия метрик

```
Стратегические KPI (компания)
    └── Операционные KPI (подразделения)
            └── Индивидуальные KPI (сотрудники)
```

## Критерии хорошего KPI (SMART+)

- **Specific** — измеряет конкретный результат
- **Measurable** — есть данные для расчёта
- **Actionable** — команда может на него влиять
- **Relevant** — связан со стратегической целью
- **Time-bound** — привязан к периоду
- **Leading vs Lagging** — опережающий (предсказывает) или запаздывающий (фиксирует)

## Типы KPI

| Тип | Пример | Назначение |
|---|---|---|
| Финансовые | Выручка, маржа, EBITDA | Результат бизнеса |
| Клиентские | NPS, Retention, Churn | Восприятие ценности |
| Процессные | Время цикла, дефекты | Эффективность операций |
| Развитие | % выполнения IDP, eNPS | Здоровье организации |

## Система управления KPI

1. Установить baseline (текущее значение)
2. Определить target (цель на период)
3. Назначить владельца KPI
4. Организовать сбор данных
5. Настроить ритм review (еженедельно / ежемесячно)
6. Реагировать на отклонения: root cause → корректирующие действия

## Ошибки

- Слишком много KPI → размывают фокус (оптимум: 3–7 на уровень)
- KPI без владельца → никто не отвечает
- Метрики без действий → информация без управления
- Только lagging KPI → узнаёшь о проблеме постфактум
