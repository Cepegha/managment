# Meeting Facilitation

Искусство и техника ведения встреч: организация процесса так, чтобы группа достигала цели встречи за минимальное время с максимальным вовлечением.

## Core Principle

Фасилитатор управляет процессом, а не содержанием. Его задача — создать условия, при которых группа сама приходит к качественному решению.

## Анатомия эффективной встречи

| Элемент | Что включает |
|---|---|
| **До встречи** | Цель, повестка, нужные участники, материалы |
| **Открытие** | Контекст, цель, правила, ожидаемый результат |
| **Работа** | Обсуждение, генерация, принятие решений |
| **Закрытие** | Решения, ответственные, сроки, follow-up |
| **После** | Minutes of Meeting в течение 24 часов |

## Типы встреч и их формат

| Тип | Цель | Оптимальное время |
|---|---|---|
| Daily Standup | Синхронизация | 15 мин |
| Weekly Team Sync | Статус + координация | 30–60 мин |
| Решение проблемы | Выбор и договорённость | 60–90 мин |
| Стратегическая сессия | Направление | Полдня / день |
| Ретроспектива | Улучшение процесса | 60–90 мин |

## Техники фасилитации

- **Parking Lot** — фиксация офтопика без потери темы
- **Round Robin** — каждый высказывается по очереди
- **Dot Voting** — быстрая приоритизация идей
- **Timeboxing** — жёсткое ограничение времени на блок
- **Liberating Structures** — структуры для вовлечения всех

## Структура продуктивной дискуссии

**Синхронизация → Расхождение → Сведение**

| Этап | Цель | Методы |
|---|---|---|
| **Синхронизация** | Общий контекст: все одинаково понимают проблему | Объяснение, вопросы на понимание |
| **Расхождение** | Генерация идей, выявление разных мнений. Критика запрещена | Мозговой штурм, письменный сбор |
| **Сведение** | Оценка и выбор лучшего варианта | Кластеризация, голосование, консенсус |

## Алгоритм статус-встречи

5 ключевых вопросов для регулярных встреч по контролю исполнения:

1. Что было **запланировано** к этому сроку?
2. Каков текущий **статус** (светофор: 🟢 зелёный / 🟡 жёлтый / 🔴 красный)?
3. В чём суть и **корневые причины** отклонений?
4. Каков **план устранения** отклонений?
5. Каков **план работы до следующей** контрольной точки?

Альтернативный формат — Scrum-совещание (стоя, 15 мин): каждый участник за 1 мин отвечает: что сделал / какие проблемы / что сделает.

## Признаки плохой встречи

- Нет цели или решения в конце
- Говорит один — слушают все
- Участники с телефонами
- Встреча могла быть письмом
- Нет follow-up, нет протокола с ответственными и сроками
