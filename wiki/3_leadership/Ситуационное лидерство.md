# Situational Leadership (Ситуационное лидерство)

Модель адаптивного лидерства, в которой стиль управления зависит от готовности сотрудника к выполнению задачи. Авторы: Пол Херси и Кен Бланшард.

## Суть

Нет универсального стиля лидерства. Эффективный лидер диагностирует готовность сотрудника (компетентность + мотивация) и выбирает соответствующий стиль.

## 4 стиля лидерства

### S1 — Directing (Указание)

- Высокое направление, низкая поддержка
- Менеджер: дает четкие инструкции, контролирует
- Для кого: новые или неопытные в этой задаче

### S2 — Coaching (Коучинг)

- Высокое направление, высокая поддержка
- Менеджер: объясняет, задает вопросы, вовлекает
- Для кого: хотят развиваться, но еще неопытны

### S3 — Supporting (Поддержка)

- Низкое направление, высокая поддержка
- Менеджер: слушает, фасилитирует, вдохновляет
- Для кого: компетентны, но нужна мотивация/уверенность

### S4 — Delegating (Делегирование)

- Низкое направление, низкая поддержка
- Менеджер: даёт автономию, минимизирует контроль
- Для кого: высокая компетентность и мотивация

## Матрица готовности (R1–R4)

```
Готовность = f(компетентность, мотивация)

R1: Low competence, High enthusiasm → S1 (Directing)
R2: Low competence, Low enthusiasm → S2 (Coaching)
R3: High competence, Low enthusiasm → S3 (Supporting)
R4: High competence, High enthusiasm → S4 (Delegating)
```

## Применение в управлении

- **Новый сотрудник**: S1 первые недели, затем переход на S2
- **Развивающийся сотрудник**: S2 → S3 по мере роста компетентности
- **High performer**: S4, но периодически возвращаемся к S3 для мотивации
- **Регрессия**: если сотрудник теряет мотивацию, может потребоваться вернуться на S3

## Ловушка: застревание в одном стиле

- Слишком много S1 → микроменеджмент, потеря инициативы
- Слишком много S2 → зависимость, замедление
- Слишком много S3 → избыточная забота, потеря чёткости
- Слишком много S4 → отсутствие руководства, фрустрация новичков

## Диагностика готовности

Вопросы для менеджера:

- Может ли сотрудник выполнить задачу без помощи?
- Хочет ли он это делать?
- Нужна ли ему уверенность?
