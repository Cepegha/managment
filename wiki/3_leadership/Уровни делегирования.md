# Уровни делегирования

Шкала из 7 уровней, описывающая степень самостоятельности сотрудника при принятии решений. Инструмент осознанного делегирования без микроменеджмента и без потери контроля.

## Core Principle

Делегирование — не бинарное «делай сам / делай ты». Между этими крайностями — 7 уровней. Менеджер выбирает уровень в зависимости от зрелости сотрудника и критичности решения.

## 7 уровней (Delegation Poker / Jurgen Appelo)

| Уровень | Название | Что делает сотрудник |
|---|---|---|
| 1 | Tell | Получает готовое решение, исполняет |
| 2 | Sell | Получает решение с объяснением «почему» |
| 3 | Consult | Высказывает мнение, решение принимает менеджер |
| 4 | Agree | Совместное решение, консенсус |
| 5 | Advise | Сотрудник решает, менеджер советует |
| 6 | Inquire | Сотрудник решает, информирует постфактум |
| 7 | Delegate | Полная автономия, без отчёта |

## Как применять

1. Определить задачу и её критичность
2. Оценить зрелость сотрудника по данной задаче (компетенция + мотивация)
3. Выбрать уровень делегирования
4. **Явно сообщить сотруднику**, какой уровень применяется
5. Постепенно повышать уровень по мере роста зрелости

## Уровни инструкций при постановке задачи

Независимо от уровня делегирования, глубина инструкции выбирается по опыту исполнителя:

| Уровень | Что передаётся | Когда применять |
|---|---|---|
| **I — Что получить** | Результат по ККСР: Количество / Качество / Сроки / Ресурсы | Всегда, обязателен |
| **II — Что делать** | Ключевые задачи и этапы | Сотрудник с опытом |
| **III — Как делать** | Детальная технология действий | Новичок |

## Обратное делегирование («обезьяна»)

Ситуация, когда сотрудник возвращает делегированную задачу руководителю — через постоянные вопросы и запросы готовых решений по мелким вопросам.

**Противоядие:** «А что ты сам предлагаешь?»

## Ошибка vs Нарушение

- **Ошибка** — неоптимальное действие в ситуации, когда правильный подход не был известен заранее. Допустима при делегировании; основа для обучения.
- **Нарушение** — пренебрежение известными правилами и стандартами. Недопустимо; требует коррекции.

## Типичные ошибки делегирования

- Делегирование без указания уровня → сотрудник не знает, насколько он свободен
- Один уровень на все задачи → либо микроменеджмент, либо потеря контроля
- Понижение уровня без объяснения → демотивирует
- «Ленивое» делегирование — «займись этим» без результата, сроков, полномочий
- Избыточное делегирование — передача прямых обязанностей (стратегия, ключевые кадровые решения)
