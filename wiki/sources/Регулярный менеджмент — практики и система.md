# Регулярный менеджмент: Практики и система

**Source:** raw/sources/notebooklm-report--2026-05-09 (6).md; raw/sources/notebooklm-report--2026-05-09.md
**Author:** Павел Безручко (Ecopsy Consulting)
**Date:** 2026-05-09

## Key Takeaways

Регулярный менеджмент — системная управленческая работа по достижению результатов руками других людей. Противостоит двум патологиям: «ручному управлению» (героизм + мобилизация) и «бюрократии» (форма важнее результата).

**Три стратегические цели:** Операционная деятельность, Команда, Изменения.

### Стандарт как инструмент: Философия Сю-Ха-Ри

- **Сю** — освоить стандарт как есть
- **Ха** — осознанно отклоняться в интересах дела
- **Ри** — улучшать стандарт на основе опыта

**Доля стандартной работы:** Линейный менеджер — 80%, Средний — 50%, Топ — 20%.

### 7 ключевых практик (методическое пособие)

**1. Планирование**

- Цель → Проблема → Результат (ККСР: Количество, Качество, Сроки, Ресурсы)
- Декомпозиция целей, буфер +25% на неопределённость, параллельные работы

**2. Делегирование и контроль**

- Три уровня инструкции: Что получить (всегда) → Что делать → Как делать (для новичков)
- Ошибка допустима, нарушение — нет. Разница критична.
- Алгоритм статус-встречи: план → статус (светофор) → причины отклонений → решение → следующий шаг
- Скрам-совещание: 3 вопроса за 1 минуту — сделал / проблемы / сделаю

**3. Обратная связь**

- Модель **НОРД** (и аналог **BORA**): Наблюдение → Описание → Реакция (пауза!) → Дальнейшие действия
- Соотношение поддерживающей к корректирующей — **3.57:1** (≈80% позитивной)
- Запрещён «метод бутерброда» — девальвирует критику

**4. Совещания**

- 5 видов: информационное, анализ/разработка, принятие решения, планёрка, статус-встреча
- Структура дискуссии: **Синхронизация → Расхождение → Сведение**
- Оптимальное число участников для решений — до 10 человек

**5. Кадровые решения**

- Подбор: метод **СТАР** (Ситуация → Требуемый результат → Активность → Результат)
- Никогда не делегировать финальное интервью, всегда проверять рекомендации
- Удержание: только тех, кого трудно заменить И у кого есть перспективы
- Увольнение: **Правило 30 секунд** — сообщить о решении в первые 30 секунд встречи

**6. Оценка эффективности и потенциала**

- Эффективность = Вклад в KPI + Соответствие ценностям
- Потенциал оценивается по **пиковым достижениям**, а не по амбициям и «блеску в глазах»
- Кадровый комитет — коллегиальное решение под председательством руководителя +1

**7. Развитие**

- Модель **70:20:10**: 70% на рабочем месте, 20% наставничество, 10% обучение
- Развитие эффективно только в **Зоне ближайшего развития** (Выготский)
- Алгоритм наставничества: Запрос → Теория → Практика → ОС → Тренировка

### Управление климатом коллектива (матрица Розина)

| Состояние | Стратегия руководителя |
|---|---|
| Благодушие (позитив + пассивность) | Разрушать иллюзии фактами |
| Скепсис (негатив + пассивность) | Жёсткая личная конфронтация |
| Тревога (негатив + активность) | Присоединение и поддержка |
| Энергия (позитив + активность) | Направить поток в бизнес-цели |

### Анализ проблем: 8 элементов описания

Симптом → Норма → Идеал → Отклонение → Последствия → Риски → Возможные причины → Корневые причины

### Матрица кадровых решений

- Высокая эфф. + Высокий потенциал → развитие, ротация, повышение
- Высокая эфф. + Соответствие должности → «Золотой фонд», экспертное развитие
- Низкая эфф. + Потенциал → PIP, анализ барьеров
- Низкая эфф. + Низкий потенциал → увольнение или понижение
