# Методическое пособие: Ключевые практики регулярного менеджмента для руководителя

**Source:** NotebookLM export, 2026-05-09\
**Date:** 2026-05-09

## Key Takeaways

- Регулярный менеджмент — системная работа ради двух целей: результат + сильная команда. Противостоит двум патологиям: «ручное управление» (героизм и мобилизация) и «бюрократия» (форма важнее результата).
- Семь ключевых практик: планирование → делегирование → обратная связь → совещания → кадровые решения → оценка эффективности → развитие сотрудников.
- **ККСР** — универсальный язык результата при постановке задач: Количество, Качество, Сроки, Ресурсы.
- Делегирование имеет три уровня инструкций: I — что получить (ККСР), II — что делать, III — как делать. Уровень выбирается по опыту исполнителя.
- **Обратное делегирование («обезьяна»)** — сотрудник возвращает задачу через постоянные вопросы. Противоядие: «А что ты сам предлагаешь?»
- Оптимальное соотношение ОС: ~3,6:1 (поддерживающая к корректирующей) ≈ 80% позитивной. Модель **НОРД**: Наблюдение → Описание → Реакция → Дальнейшие действия.
- Структура продуктивной дискуссии: **Синхронизация → Расхождение → Сведение**.
- Статус-встреча строится на 5 вопросах: план / статус (светофор) / причины отклонений / план устранения / план до следующей точки.
- Кадровые решения важнее стратегии: «Кто» — важнее «Что». Метод поведенческого интервью **СТАР**: Ситуация → Требуемый результат → Активность → Результат.
- Оценка потенциала — по пиковым достижениям (уровни Джекса); оценка эффективности — интегрально за период (вклад в результат + соответствие принципам).
- Развитие: модель **70:20:10** (70% — рабочий опыт, 20% — социальное обучение, 10% — формальное). Цикл Колба: опыт → рефлексия → концептуализация → применение.

## Unique Concepts

- **ККСР** — фреймворк для описания результата (Количество / Качество / Сроки / Ресурсы)
- **НОРД** — практический алгоритм обратной связи (Наблюдение / Описание / Реакция / Дальнейшие действия)
- **СТАР** — метод поведенческого интервью при подборе
- **Кадровый комитет** — совещание руководителей для калибровки оценок и кадровых решений
- Различие **ошибка vs нарушение** при делегировании
