# 11 философских бритв

**Source:** https://reminder.media/post/philosophical-razors\
**Author:** Сергей Панков\
**Date:** 2026-05-11

## Key Takeaways

- Философские бритвы — короткие алгоритмы отсечения лишнего в рассуждениях; экономят когнитивный ресурс
- Бремя доказательства всегда лежит на том, кто утверждает, а не на том, кто слушает
- «Не спеши отменять правило, если не знаешь, зачем его ввели» — ключевое для менеджмента

## 11 бритв

| Бритва | Суть |
|---|---|
| **Оккама** | Начни с простейшего объяснения; не умножай сущности без необходимости |
| **Чаттона** | Если одного объяснения мало — добавляй; не упрощай сверх меры |
| **Стандарт Сагана** | Экстраординарные утверждения требуют экстраординарных доказательств |
| **Хитченса** | Утверждение без доказательств не требует опровержения — бремя на утверждающем |
| **Олдера** | Спорить стоит только о том, что можно проверить (принцип фальсифицируемости Поппера) |
| **Хэнлона** | Не объясняй злым умыслом то, что объясняется глупостью или рассеянностью |
| **Принцип утки** | Если всё указывает на одно — делай вывод; судить по поведению, не по оправданиям |
| **Холмса** | Когда исключены все обычные объяснения — рассматривай странное |
| **Гильотина Юма** | «Так было» не означает «так правильно»; факт ≠ норма |
| **Фейнмана** | Если нельзя объяснить просто — возможно, сам не понимаешь |
| **Забор Честертона** | Не отменяй правило, пока не понял, зачем оно введено |

## Применение в менеджменте

- **Хэнлона** — при разборе ошибок команды: презумпция добросовестности
- **Честертона** — перед отменой регламентов или процессов
- **Хитченса** — на совещаниях: «это точно не сработает» без аргументов = повод уточнить, а не возражать
- **Оккама** — при диагностике проблем: сначала простые причины
- **Гильотина Юма** — «у нас всегда так» — не аргумент
