# Карта инструментов менеджера

**Source:** raw/sources/manager\_tools\_and\_competencies.md\
**Date:** 2026-05-09

## Key Takeaways

- Современный менеджмент — это не только POLC (Plan-Organize-Lead-Control), а 14 функциональных блоков
- Стандартизация рутины освобождает когнитивный ресурс для стратегии
- Главная задача менеджера — архитектор системы, а не контролёр задач
- Матрица зрелости управления: от Хаоса (уровень 1) до Самообучающейся системы (уровень 5)

## Архитектура компетенций (14 блоков)

| Блок | Ключевые инструменты |
|---|---|
| Стратегическое управление | SWOT, OKR, BSC, Blue Ocean, Eisenhower |
| Планирование | Roadmap, Kanban, GTD, RACI |
| Организация процессов | BPMN, Lean, Kaizen, PDCA, 5S |
| Делегирование | Situational Leadership, Delegation Poker |
| Контроль | KPI, SLA, 5 Why, Root Cause Analysis |
| Управление людьми | 1:1, GROW, SBI, Radical Candor, 360 |
| Коммуникации | BATNA, NVC, Thomas-Kilmann |
| Управление изменениями | ADKAR, Kotter 8 Steps |
| Принятие решений | Cynefin, RAPID, Decision Tree |
| Управление проектами | Scrum, Kanban, PMBOK |
| Управление знаниями | SOP, Wiki, Playbooks |
| Финансовое управление | P\&L, Cash Flow, Unit Economics |
| Метрики и аналитика | KPI, NPS, eNPS, BI |
| Цифровые инструменты | Jira, Notion, Slack, Zapier |

## Матрица зрелости управления

| Уровень | Характеристика |
|---|---|
| 1 — Хаос | Нет регламентов, всё держится на руководителе |
| 2 — Операционный | Есть планирование, контроль задач, регулярные встречи |
| 3 — Системный | Формализованы процессы, введены KPI, делегирование работает |
| 4 — Масштабируемый | Управление через систему, метрики, руководители 2-го уровня |
| 5 — Управляемая организация | Data-driven, самообучающаяся система, непрерывные улучшения |

## Матрица компетенций по уровням

| Компетенция | Junior | Middle | Senior | Executive |
|---|---|---|---|---|
| Планирование | Базовое | Системное | Стратегическое | Корпоративное |
| Делегирование | Частичное | Регулярное | Масштабируемое | Через лидеров |
| Контроль | Операционный | KPI | Управление системой | Управление бизнесом |
| Лидерство | Управление задачами | Управление людьми | Управление изменениями | Формирование культуры |

## Метакомпетенции

- **Личностные:** самоорганизация, устойчивость, самодисциплина
- **Когнитивные:** критическое, системное, аналитическое мышление
- **Социальные:** эмпатия, влияние, убеждение
- IFPM выделяет: Managing Self / Managing Others / Managing the Business
