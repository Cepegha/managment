# Kaizen & Gemba Playbook 1: Дистрибьютор

**Source:** raw/sources/Kaizen\_Gemba\_Playbook\_Distributor.md\
**Date:** 2026-05-20

## Key Takeaways

- Kaizen (改善) = «изменение к лучшему» — эволюция, не революция: малые шаги каждый день vs крупные проекты раз в 5 лет
- Гемба (現場) = «реальное место работы» — все ответы на «почему» находятся там, а не в Excel
- Принцип Genchi Genbutsu: «иди и смотри» — Тайити Оно стоял в меловом круге часами, наблюдая за процессом
- В дистрибуции Гемба = торговая точка, склад, маршрут торгового представителя, кабина грузовика
- Управление через отчёты — классическая болезнь: за цифрой 87% выполнения плана могут скрываться четыре совершенно разных причины

## Пять принципов Kaizen в дистрибуции

1. **Малые шаги** — начни с ежедневного отчёта ТП, не с CRM за 5 млн
2. **Стандартизация** — улучшение без стандарта = разовое событие; улучшение + стандарт = новая точка отсчёта
3. **Устранение Muda** — всё, что не создаёт ценности для клиента (лишние переговоры, ожидание, повторный ввод данных)
4. **Вовлечение сотрудников** — ТП знает о проблемах клиента лучше коммерческого директора
5. **Культура непрерывных улучшений** — утренние встречи, доски KPI, предложения улучшений, follow-up по контрмерам

## Архитектура TPS

```
TOYOTA PRODUCTION SYSTEM
├── JUST-IN-TIME (точно вовремя): Kanban, Pull-flow, Heijunka
└── JIDOKA (автономность/качество): Andon, Poka-Yoke, Stop-line
    └── KAIZEN (фундамент): Стандартизация, Muda, PDCA, 5S
```

- **TPS** — конкретная система Toyota
- **Lean** — адаптация TPS для любой отрасли (MIT, 1990)
- **Kaizen** — философия и культура, основа TPS и Lean

## Gemba Walk для менеджеров дистрибуции

| Роль | Где находится Гемба |
|---|---|
| Коммерческий директор | Торговые точки, встречи с ключевыми клиентами |
| Руководитель отдела продаж | В поле с торговыми представителями |
| Супервайзер | На маршруте ТП, в торговых точках |
| Операционный директор | Склад, машины доставки |
| Руководитель склада | Зоны приёмки, сборки, отгрузки |

## Kaizen vs Традиционный менеджмент

| Параметр | Западный менеджмент | Kaizen |
|---|---|---|
| Горизонт | Крупные проекты раз в 2–5 лет | Малые шаги каждый день |
| Инициатор | Топ-менеджмент | Каждый сотрудник |
| При ошибке | Ищется виновный | Ищется причина |
| Устойчивость | Часто временная | Встроена в культуру |
