# Standard Work

Документально зафиксированный лучший известный метод выполнения операции. Основа стабильности и базовая точка для следующего Kaizen-улучшения.

## Core Principle

Стандарт — не ограничение. Это текущий лучший способ, который обязателен для соблюдения до тех пор, пока не найден способ лучше. Без стандарта невозможно улучшение: нечего улучшать.

> «Стандартизация сегодня — это фундамент улучшений завтра» — Тайити Оно

## Что входит в Standard Work

- Последовательность шагов операции
- Время выполнения каждого шага (Takt Time)
- Необходимые материалы и инструменты
- Критические точки качества
- Визуальные элементы (схемы, фото)

## Связь с Kaizen

Standard Work и [[Kaizen]] работают в паре:

1. Есть стандарт → соблюдаем (SDCA)
2. Нашли улучшение → [[PDCA]] → проверили → стандарт обновлён
3. Новый стандарт → снова соблюдаем

Каждый Kaizen-цикл заканчивается обновлением стандарта. Иначе улучшение не закрепится.

## Yokoten

Стандарт, найденный в одной зоне, должен быть передан в другие — это [[Yokoten]]. Standard Work — носитель лучшей практики.
