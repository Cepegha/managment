# Профессиональная устойчивость

Умение справляться с рабочим стрессом и переменами, сохраняя продуктивность и извлекая уроки из опыта. Не врождённая черта, а набор конкретных навыков.

## Core Principle

Два базовых компонента: аналитическое мышление + способность восстанавливаться после стресса. Ключевое — не отсутствие стресса, а умение снова браться за дело после него.

## 9 навыков (WEF Future of Jobs 2025)

| Навык | Суть |
|---|---|
| Критическое мышление | Валидные данные → правильная структура → логичный вывод |
| Адаптивность в обучении | Готовность быть новичком; не бояться признавать пробелы |
| Работа с ИИ | Инструмент увеличения эффективности, не замена мышлению |
| Самоэффективность | Вера в свои способности + ощущение контроля над ситуацией |
| Социальная опора | Сильные связи с коллегами и наставниками; просить помощи |
| Управление энергией | Грамотное распределение сил; циклы 90–120 мин |
| Эмоциональная саморегуляция | Переоценка ситуации снижает стресс; «сложная, но справлюсь» |
| Смысл и направленность | Цели, соотнесённые с ценностями, выдерживают турбулентность |
| Структурное решение проблем | Упорядочить задачу → один следующий шаг за раз |

## Практики развития

- **Адвокат дьявола** — найди 2–3 аргумента против своего решения
- **Круг влияния** — что в моей власти vs внешние факторы
- **Энергетический аудит** — 7 дней отслеживать «+» и «−» энергию
- **Письмо из будущего** — опиши удачный профессиональный год через год
