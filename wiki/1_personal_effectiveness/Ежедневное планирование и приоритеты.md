# Ежедневное планирование и управление приоритетами

Система организации дневной работы через последовательное планирование, приоритизацию задач и выполнение в порядке важности.

## Problem

**Типичные проблемы:**

- Много задач в голове → когнитивная перегрузка → паралич
- Неясные приоритеты → работаешь над неправильным
- Реактивный режим → весь день уходит на пожары, а на важное не остаётся времени
- Неправильный порядок → сложные задачи откладываются, растёт стресс

**Результат:** Конец дня, а ничего не сделано (или сделано, но не то).

## Solution: 3-Layer Planning

### Layer 1: Long-term vision (5-20+ лет)

**Зачем:** Понять, что действительно важно в жизни и работе.

**Как:**

1. Ответить на вопрос: Где я хочу быть через 20 лет?
2. Какие области жизни важны? (семья, здоровье, карьера, финансы, развитие)
3. Какие цели в каждой области?

**Результат:** Компас, по которому ориентироваться при выборе приоритетов.

**Инструмент:** [[Личная стратегия владельца]] — долгосрочное видение жизни

### Layer 2: Monthly/Quarterly Planning

**Зачем:** Разбить долгосрочные цели на управляемые отрезки.

**Как:**

1. Определить, какие 2-3 больших результата хочу достичь в этом месяце/квартале
2. Для каждого результата — определить ключевые инициативы
3. Забронировать время на эти инициативы

**Результат:** Ясная дорожная карта на месяц/квартал.

**Инструмент:** [[OKR]] — система целеполагания для этого слоя

### Layer 3: Daily Planning

**Зачем:** Перевести стратегию в конкретные действия.

**Как:**

**Вечером (перед сном):**

1. Составить список всех задач на завтра (без фильтра)
2. Добавить новые задачи, которые появились во время дня
3. Обновить статусы текущих проектов

**Утром (первое дело):**

1. Обновить список (что-то могло измениться за ночь)
2. Приоритизировать (см. ниже)
3. Выбрать 1-3 задачи для выполнения (не пытайся делать всё)

**Результат:** Ясный план на день, чувство контроля.

## Prioritization: ABVCD Method

Классификация задач по приоритету:

### A — Biggest Faryg (самая большая лягушка)

**Критически важно:**

- Связано с долгосрочными целями (Layer 1)
- Принесёт наибольший результат
- Часто это самая сложная/неприятная задача

**Правило:** Делать **первым делом**, пока энергия высока.

**Пример:**

- Написать стратегию компании
- Подготовить презентацию инвестору
- Провести сложный разговор с сотрудником

### B — Should Do (стоит сделать)

**Важно, но не критично:**

- Вносит вклад в цели
- Можно отложить на день-два без катастрофы

**Правило:** Делать после А, если есть время и энергия.

**Пример:**

- Обновить статус проекта
- Ответить на письма
- Провести планерку

### C — Nice to Do (было бы неплохо)

**Интересно, но может отложиться:**

- Не связано прямо с целями
- Можно делегировать или исключить

**Правило:** Делать только если выполнены A и B.

**Пример:**

- Прочитать интересную статью
- Отписать комментарий
- Пересмотреть старый документ

### D — Delegate (делегировать)

**Может делать кто-то другой:**

- Требует чужих компетенций
- Развивает других людей
- Освобождает твоё время для A

**Правило:** Делегировать немедленно с ясными сроками.

**Пример:**

- Подготовить отчёт (стажёр)
- Организовать встречу (ассистент)
- Привести примеры (intern)

### E — Eliminate (исключить)

**Нужно ли это вообще?**

- Не связано с целями
- Съедает время без результата
- Часто это «привычные» дела, которые никогда не пересматривались

**Правило:** Исключить без угрызений совести.

**Практика:** Раз в неделю спросить себя: какую одну задачу я могу вычеркнуть?

## Daily Execution: Eating the Frog First

### Принцип: Съесть лягушку с утра

**Лягушка** = самая большая, самая неприятная, самая важная задача.

**Почему с утра?**

- Утром энергия максимальна
- Ментальный ресурс свежий
- После лягушки всё остальное кажется лёгким
- Психологически легче (худшее сделано)

**Как это работает:**

1. Проснулся → минимум процедур (кофе, душ)
2. Сразу к лягушке (на свежую голову, без интернета)
3. 90 минут глубокой работы
4. Только потом — коммуникация, встречи, текущие дела

**Результат:** День структурирован, главное сделано, остальное бонус.

### Техники для выполнения

#### 1. Step-by-Step (разбить на шаги)

Большая задача → маленькие видимые шаги.

**Пример:**

- Вместо «написать стратегию» → «написать видение» → «написать ключевые инициативы» → «написать plan»

**Психология:** Маленькие победы мотивируют продолжать.

#### 2. Single-tasking (однозадачность)

Одна задача в один момент времени. Без переключений.

**Как:** Отключить уведомления, закрыть лишние вкладки, установить таймер.

**Результат:** Качество выше, время короче, стресс ниже.

#### 3. Time Blocking (сегментация времени)

Разные блоки времени для разных типов работы:

- Блок 1 (8-10): Глубокая работа (лягушка)
- Блок 2 (10-12): Встречи, планирование
- Блок 3 (13-14): Коммуникация, текущие дела
- Блок 4 (14-16): Второй раунд глубокой работы
- Блок 5 (16-17): Рефлексия, планирование на завтра

**Результат:** Ритм работы, тело привыкает, производительность растёт.

## Weekly Rhythm: The Weekly Review

Один раз в неделю (обычно в пятницу) — обзор и переплани­рование.

**Что делать (30-60 минут):**

1. Обработать Inbox (все накопившиеся задачи, идеи, статьи)
2. Проверить текущие проекты (что сделано, что застряло)
3. Обновить списки (A/B/C/D/E переклассификация)
4. Спланировать следующую неделю (какие A-задачи)
5. Рефлексия (что хорошо, что плохо, что изменить)

**Результат:** Система не деградирует, остаёшься в контроле.

## Common Pitfalls

### 1. Делать C и D вместо A

**Проблема:** C-задачи кажутся быстрыми, даёшь им приоритет, а A откладываешь.

**Решение:** Обещай себе, что A — всегда первое. Даже если это займёт весь день.

### 2. Переполненный список

**Проблема:** Слишком много задач → не можешь выбрать, из-за чего ничего не делаешь.

**Решение:** Максимум 3 A-задачи на день. Остальное подождёт.

### 3. Отсутствие долгосрочного видения

**Проблема:** Планируешь дни, но не ясно, куда идёшь → работаешь над чужими целями.

**Решение:** Сначала Layer 1 (личная стратегия), потом Layer 2-3.

### 4. Отсутствие отдыха

**Проблема:** Каждый день — лягушки, нет перерывов → выгораешь.

**Решение:** Включить отдых в систему. 1 день в неделю — без работы.
