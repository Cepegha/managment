# Getting Things Done (GTD)

Система управления задачами и информацией, основанная на принципе полного опорожнения ума. Основатель: Дэвид Аллен.

## Суть

GTD решает проблему когнитивной перегрузки: если задачи только в голове, она не может сосредоточиться на работе. Система переводит все входящее во внешнюю систему, оставляя ум свободным для анализа.

## Цикл GTD (5 шагов)

1. **Capture** — захват всех идей и задач в Inbox (без фильтра)
2. **Clarify** — обработка: является ли это действием? Если нет — в архив/справка; если да — определить результат
3. **Organize** — раскладка по проектам, контекстам, временной шкале
4. **Reflect** — еженедельный обзор (Weekly Review)
5. **Engage** — выполнение с уверенностью в результате

## Ключевые компоненты

### Входящая корзина (Inbox)

- Временное хранилище всего, что требует обработки
- Цель: нулевой inbox в конце недели

### Контексты

- @Home, @Office, @Calls, @Computer, @Errands
- Категоризация по условиям выполнения, не по проектам

### Проекты

- Результат требует более одного шага
- Отслеживание в отдельном списке проектов

### Someday/Maybe

- Идеи для долгосрочного рассмотрения
- Периодический пересмотр (раз в месяц)

### Еженедельный обзор

- 30–60 минут на согласование системы
- Обработка Inbox, проверка проектов, планирование

## Применение в управлении

- Менеджер использует GTD для управления своим потоком работы
- Команда может использовать принцип контекстов для асинхронной работы
- Weekly Review как ритуал для постановки целей на неделю
