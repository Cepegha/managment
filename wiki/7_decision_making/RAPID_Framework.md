# RAPID Framework

Инструмент Bain & Company для прояснения ролей в процессе принятия решений в организации. Устраняет двусмысленность «кто решает» и «кто согласует».

## Core Principle

Большинство организационных дисфункций — следствие непрозрачного процесса принятия решений. RAPID делает роли явными до того, как решение принимается.

## Пять ролей

| Буква | Роль | Функция |
|---|---|---|
| **R** | Recommend | Предлагает решение с анализом вариантов |
| **A** | Agree | Должен согласиться (право вето). Обычно 1–2 человека |
| **P** | Perform | Исполняет принятое решение |
| **I** | Input | Предоставляет данные и экспертизу для R |
| **D** | Decide | Принимает финальное решение. Только один человек |

## Как применять

1. Перечислить ключевые типы решений в организации/процессе
2. Для каждого типа решений назначить роли RAPID
3. Убедиться: **D** — всегда один
4. Согласовать матрицу с командой
5. Использовать при возникновении конфликтов «кто решает»

## Отличие от RACI

| | RACI | RAPID |
|---|---|---|
| Фокус | Задачи и работа | Решения |
| Применение | Проекты, процессы | Организационные решения |
| Детализация | Операционная | Стратегическая |

## Типичные проблемы без RAPID

- «Мы все договорились» — но никто не принял решение
- Бесконечное согласование — слишком много A
- Решение принято, никто не исполняет — нет явного P
