# RACI Matrix

Инструмент распределения ролей и ответственности между участниками проекта или процесса. Устраняет неясность: кто принимает решения, кто делает, кто согласует.

## Core Principle

Каждая задача или решение имеет четыре роли. У каждой задачи — ровно один **A** (Accountable). Без этого правила матрица не работает.

## Четыре роли

| Буква | Роль | Суть |
|---|---|---|
| **R** | Responsible | Выполняет работу. Может быть несколько. |
| **A** | Accountable | Отвечает за результат перед организацией. Один. |
| **C** | Consulted | Даёт экспертизу до/во время выполнения. Двусторонняя коммуникация. |
| **I** | Informed | Получает информацию о результате. Односторонняя коммуникация. |

## Как строить

1. Перечислить все задачи/решения по вертикали
2. Перечислить все роли/должности по горизонтали
3. Для каждой задачи назначить R, A, C, I
4. Проверить: у каждой задачи ровно один A
5. Проверить: нет строк без R

## Сигналы проблем в матрице

- Много A у одного человека → перегрузка
- Много C и I → избыточное согласование
- Нет R у задачи → никто не делает
- Нет A → никто не отвечает

## Применение

- Запуск нового процесса или проекта
- Реорганизация команды
- Онбординг новых сотрудников
- Устранение конфликтов «это не моя задача»
