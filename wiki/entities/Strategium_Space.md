# Strategium.Space

Консультационная и образовательная платформа по стратегическому управлению организациями.

## Overview

**Веб:** https://strategium.space/\
**Основатель:** [[Dmitry Rytsev]]\
**Компания:** ООО «Совершенные индустрии»

## Основные продукты

### 1. Периодическая система стратегических элементов

Визуальный инструмент для навигации по 76 методам и инструментам стратегического управления. Доступна в нескольких вариантах дизайна для печати и использования в высоком разрешении.

### 2. Методология разработки стратегии (12 этапов)

Структурированный процесс, позволяющий разработать стратегию развития компании любого размера:

- Анализ (PESTLE, SWOT)
- Целеполагание (миссия, видение)
- Планирование (стратегические инициативы, ресурсное планирование)
- Каскадирование и синхронизация
- Мониторинг реализации

### 3. Методология аудита (Strategium Space Score)

20-критериальный аудит качества системы стратегического управления, основанный на научной методологии. Выполняется на основе анкетирования менеджеров разных уровней.

### 4. Онлайн-практикумы

Самостоятельные программы обучения для команд:

- Экспресс-аудит системы управления
- Разработка стратегии развития
- Внедрение системы стратегического управления
- С опцией дистанционной поддержки консультанта

## Программа модернизации

Полный цикл проектов для повышения долгосрочной конкурентоспособности:

1. **Экспресс-аудит** (1 неделя) — оценка текущего состояния системы управления
2. **План мероприятий** (1 неделя) — план проведения стратегических сессий
3. **Разработка стратегии** (4-12 недель) — проведение стратегических сессий
4. **Внедрение системы** (~12 недель) — внедрение процессно-ориентированного управления
5. **Реализация стратегии** (5-10 лет) — реализация и постоянная корректировка

Каждый проект может быть выполнен командой предприятия самостоятельно (по методологии) или с поддержкой консультанта.

## Global Research

**100+ компаний** из разных стран прошли аудит по Strategium Space Score. Исследование показывает:

- Средняя оценка качества стратегического управления: ~40% от максимума
- Ключевые проблемные области:
  - Содержание стратегии (45%)
  - Стратегические процессы (35%)
  - Реализация стратегии (зависит от процессов)
