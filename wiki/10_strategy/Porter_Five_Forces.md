# Porter's Five Forces

Модель Майкла Портера (1979) для анализа конкурентных сил, определяющих привлекательность отрасли и долгосрочную прибыльность бизнеса.

## Core Principle

Прибыльность определяется не продуктом, а структурой отрасли. Пять сил формируют конкурентное давление, которое распределяет ценность между игроками.

## Пять сил

### 1. Конкуренция внутри отрасли

Интенсивность борьбы между существующими игроками.

- Много игроков одинакового размера → высокая конкуренция
- Медленный рост рынка → война за долю
- Высокие барьеры выхода → игроки не уходят даже при убытках

### 2. Угроза новых игроков

Насколько легко войти в отрасль.

- Высокие барьеры входа (капитал, регуляторика, бренд) → слабая угроза
- Сетевые эффекты у действующих игроков → защита

### 3. Угроза субститутов

Насколько легко клиент переключится на альтернативный продукт/услугу.

- Субститут лучше/дешевле → потолок цены ограничен
- Низкие переключательные издержки → высокая угроза

### 4. Рыночная власть покупателей

Способность клиентов диктовать условия.

- Мало крупных покупателей → высокая власть
- Стандартизированный продукт → легко переключиться

### 5. Рыночная власть поставщиков

Способность поставщиков диктовать условия.

- Мало поставщиков уникального ресурса → высокая власть
- Дорогое переключение → зависимость

## Вывод из анализа

Чем сильнее каждая из пяти сил, тем ниже привлекательность отрасли. Стратегия строится вокруг:

- Выбора позиции, где силы слабее
- Изменения конфигурации сил в свою пользу (Blue Ocean)
- Построения барьеров против конкретных сил
