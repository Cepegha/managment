# SWOT / PESTEL

Два базовых инструмента стратегического анализа: **SWOT** — внутренняя и внешняя среда компании; **PESTEL** — макроокружение.

---

## SWOT

Матрица из четырёх квадрантов для оценки стратегического положения.

| | Внутреннее | Внешнее |
|---|---|---|
| **Позитивное** | Strengths (сильные стороны) | Opportunities (возможности) |
| **Негативное** | Weaknesses (слабые стороны) | Threats (угрозы) |

### Как использовать

Сам по себе SWOT — инвентаризация. Ценность создаёт **SWOT-матрица стратегий**:

- **SO** — как использовать сильные стороны для захвата возможностей
- **WO** — как преодолеть слабости, используя возможности
- **ST** — как сильные стороны помогут противостоять угрозам
- **WT** — как минимизировать слабости и угрозы одновременно

### Ошибки

- Слишком длинные списки без приоритизации
- Анализ без выводов и стратегических решений
- Делается раз в год и кладётся в стол

---

## PESTEL

Анализ шести факторов макросреды, которые влияют на бизнес извне.

| Фактор | Примеры |
|---|---|
| **Political** | Политическая стабильность, регуляторная политика, налоги |
| **Economic** | ВВП, инфляция, курсы валют, процентные ставки |
| **Social** | Демография, ценности, поведение потребителей |
| **Technological** | Инновации, автоматизация, цифровизация |
| **Environmental** | ESG-требования, климат, природные ресурсы |
| **Legal** | Законодательство, трудовое право, IP |

### Как использовать

1. Перечислить факторы по каждому блоку
2. Оценить значимость и вероятность для бизнеса
3. Перенести ключевые факторы в SWOT (O и T)

## Связь между инструментами

PESTEL → питает блоки O и T в SWOT → SWOT → основа стратегических решений
