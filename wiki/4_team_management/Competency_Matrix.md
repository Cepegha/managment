# Competency Matrix

Матрица компетенций — инструмент оценки и визуализации уровня владения ключевыми навыками внутри команды. Показывает сильные стороны и разрывы.

## Core Principle

Не все компетенции одинаково важны для всех ролей. Матрица позволяет явно договориться, что ожидается на каждом уровне, и сделать развитие прозрачным.

## Структура

- **По вертикали**: компетенции (технические + управленческие + личностные)
- **По горизонтали**: уровни (Junior / Middle / Senior / Lead / Manager)
- **В ячейках**: описание наблюдаемого поведения или оценка (0–4)

## Шкала оценки (пример)

| Уровень | Описание |
|---|---|
| 0 | Не владеет |
| 1 | Базовое — делает под руководством |
| 2 | Уверенное — делает самостоятельно |
| 3 | Экспертное — обучает других |
| 4 | Лидерское — формирует стандарт в компании |

## Применение

- **Найм**: определить профиль кандидата
- **Оценка**: калибровка команды
- **Развитие**: основа для IDP
- **Карьерные треки**: что нужно для перехода на следующий уровень
- **Планирование**: выявить критические разрывы в команде

## Ошибки

- Слишком много компетенций → матрица теряет фокус (оптимум: 5–10)
- Размытые формулировки → субъективность оценки
- Оценка без обсуждения → сотрудник не понимает, как расти
- Матрица без обновления → устаревает вместе с ролями
